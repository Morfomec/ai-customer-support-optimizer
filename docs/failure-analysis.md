Failure Analysis

## Main Problem

The AI sometimes claims that it can access systems or perform actions that were not provided.

## Root Cause

### Prompt Issue

The baseline prompt does not tell the AI how to handle missing information or unavailable systems.

### Context Issue

The AI was not given access to:

- Customer accounts
- Order tracking
- Payment systems
- Refund policies
- Support schedules

### Logic Issue

No major logic issue was found. The basic workflow works as expected.

## Conclusion

The main problem is a combination of a weak prompt and missing context. The prompt needs clear rules for handling information and actions that are not available.
