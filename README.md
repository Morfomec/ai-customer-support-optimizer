# AI Customer Support Optimizer

A simple project to evaluate and improve an AI customer support prompt.

## Goal

Improve AI responses for:

- Accuracy
- Consistency
- Efficiency
- Avoiding unsupported claims

## Process

1. Created a baseline prompt.
2. Tested the baseline using Groq API.
3. Evaluated the responses.
4. Identified unsupported claims as the main problem.
5. Created an optimized prompt.
6. Tested the optimized prompt using the same test cases.
7. Compared the results.

## Results

Baseline Score: **6.5/10**

Optimized Score: **9/10**

Improvement: **+2.5 points**

## Tools Used

- Python
